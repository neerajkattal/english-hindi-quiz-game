# Backend (FastAPI)

Small API for the English to Hindi quiz game.

## Files

- `main.py` — the FastAPI app and route definitions
- `data.py` — the hardcoded list of English/Hindi word pairs
- `models.py` — Pydantic request/response models
- `quiz.py` — quiz logic (picking questions, checking answers)

## Setup

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Endpoints

| Method | Path            | Description                                  |
|--------|-----------------|-----------------------------------------------|
| GET    | `/`             | Health check                                   |
| GET    | `/quiz/question`| Get a new random question with 4 Hindi choices |
| POST   | `/quiz/answer`  | Submit `{english_word, selected_hindi}`        |

Interactive API docs are auto-generated by FastAPI at `/docs` once the
server is running.
