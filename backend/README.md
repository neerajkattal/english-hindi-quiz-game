# Backend (FastAPI)

Small API for the English to Hindi quiz game.

## Files

- `main.py` — the FastAPI app and route definitions
- `data.py` — the hardcoded list of English/Hindi word pairs, each tagged with a category
- `models.py` — Pydantic request/response models
- `quiz.py` — quiz logic (picking questions, optionally by category, checking answers)

## Setup

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Endpoints

| Method | Path              | Description                                                  |
|--------|-------------------|----------------------------------------------------------------|
| GET    | `/`               | Health check                                                    |
| GET    | `/categories`     | List available word categories                                  |
| GET    | `/quiz/question`  | Get a new random question with 4 Hindi choices; accepts an optional `?category=` filter |
| POST   | `/quiz/answer`    | Submit `{english_word, selected_hindi}`                          |

Interactive API docs are auto-generated by FastAPI at `/docs` once the
server is running.

Note: answer streaks and per-topic high scores are tracked entirely on the
frontend (in `localStorage`) — the backend stays stateless and only knows
about individual questions and answers.
